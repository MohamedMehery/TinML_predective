## 1. Project Purpose
This laboratory operates on a **research-to-impact** model. The initial focus domain is **Embedded AI / TinyML / Machine Fault Diagnosis / Predictive Maintenance**. 

The long-term objective is to produce reproducible scientific contributions, rigorous evidence, and published artifacts. Practical prototypes serve strictly as validation tools for well-formulated research questions.

**Research Path Workflow**:
`Literature → Evidence → Synthesis → Research Gap → Research Question → Data Feasibility → Experiment → Embedded Validation → Contribution → Paper / Public Artifact → Academic / Industry Opportunities`
