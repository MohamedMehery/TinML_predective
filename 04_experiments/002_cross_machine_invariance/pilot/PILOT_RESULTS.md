## 1. Authoritative pilot result (second, complete run)

**Configuration** (from `PILOT_T12_meta.json`):
- Source: CWRU (12 kHz), 7 source LOBO folds (3 IR + 1 Healthy + 3 OR;
  Ball excluded by the 3-class contract per `load_pilot_dataset(include_ball=False)`).
- Target: PU (64 kHz, downsampled to 12 kHz), 13 target UIDs (3 Healthy
  + 5 OR + 5 IR; KB23/24/27 excluded by the synthetic generator's
  `fault_class="Ball"` mapping and `--include-ball=False`).
- Representations (5): R1_Raw, R1_Env, R2_Raw, R2_Env, R3_Order.
- Seeds: 5 (42, 1337, 2026, 7, 99).
- Cluster bootstrap on `physical_bearing_uid`: n=10,000, CI=0.95.
- Synthetic data only (`pilot/synthetic/raw_data/*.npz`, generated by
  `pilot/synthetic/src/generate_synthetic_benchmark.py`; the `.npz`
  files are `.gitignore`-d and not in the repository).

**Headline aggregate** (from `PILOT_T12_summary.csv`; ddof=0 std):

**Per-UID F1 distribution** (from `PILOT_T12_per_uid_f1.csv`,
n=35 per UID per rep; the headline pattern):

- R1_Raw: predicts IR (KI*) with F1 ≈ 1.00, Healthy (K0*) with F1
  ≈ 0.37-0.41, OR (KA*) with F1 ≈ 0.02 (i.e., R1_Raw on this
  synthetic data is essentially a binary "IR vs not-IR" classifier).
- R3_Order: predicts Healthy (K0*) with F1 ≈ 0.86, OR (KA*) with F1
  ≈ 0.14, IR (KI*) with F1 ≈ 0.003 (i.e., R3_Order on this synthetic
  data is essentially a binary "Healthy vs not-Healthy" classifier).
- The 175 runs and 2275 per-UID rows are internally consistent
  (summary mean/min/max match the per-run aggregation exactly).

**What this pilot can establish:**
- The pipeline (`preprocess.py`, `datasets.py`, `train.py`,
  `evaluate.py`, `run_pipeline.py`) executes end-to-end on the
  synthetic benchmark and produces the contracted output schema.
- The LOBO splitting, source-train z-score, and cluster bootstrap CI
  behave as designed.
- The seed-to-seed variance is small relative to the per-UID bootstrap
  variance (5-seed F1 range within a fold is ~0.10 absolute, vs ~0.20
  bootstrap CI half-width).

**What this pilot CANNOT establish:**
- The C5/C8 hypothesis on **real** cross-machine transfer. The pilot
  is **synthetic**, generated by a deterministic physical-dynamics
  model. The signal structure (modulation, fault impulses, structural
  resonance) is the generator's design, not a measurement.
- Whether the H0 (R3_Order collapses by ≥ 35%) or H1 (R3_Order ≤ 15%
  degradation) holds on real CWRU↔PU data. The pilot numbers do not
  adjudicate the C5/C8 hypothesis.

**Direction observed on synthetic data:** R3_Order (0.136) and R2_Env
(0.137) are **worse** than R1_Raw (0.473) and R2_Raw (0.499) on this
synthetic T12 transfer, with R3_Order near chance (3-class chance =
0.333; the per-UID F1 ≈ 0.003 for IR indicates R3_Order predicts
almost everything as Healthy). This is a **pilot-only** observation; it
is NOT evidence against the C5/C8 hypothesis on real data, but it is
evidence that the synthetic generator's signal structure does not
favour R3_Order. The C5/C8 hypothesis is about real cross-machine
transfer, and the pilot is not a test of the hypothesis.

**Observations from the 30-run partial transcript** (preserved for
provenance, not as a result):
- **R1_Raw fold asymmetry:** when the held-out source UID is a fault
  class (IR/OR), the cross-machine F1 lands in 0.43-0.55 range. When
  the held-out UID is the only Healthy UID (CWRU_N), F1 drops to
  0.23-0.27. This is consistent with LOBO: removing the only Healthy
  UID forces the model to over-predict fault on the target.
- **R1_Raw seed variance:** within each fold, the 5 seeds produce F1
  values within a ~0.10 absolute range. The 95% CIs on the bootstrap
  (n=10,000) are wider than the seed-to-seed range, so the per-UID
  bootstrap variance dominates.
- **R3_Order was not reached** in the first pilot. The smoke test
  before the first pilot showed R3_Order = 0.13 (1 fold, 1 seed,
  bootstrap n=200). The second pilot, which completed, confirms
  R3_Order = 0.136 on the full 5×7×5 grid (very close to the smoke
  number).

## 5. What is NOT in this commit (negative claims)

Per the C5/C8 charter's Major Non-Claims and per Phase 20 audit:
- The pilot does NOT establish the C5/C8 hypothesis on real data.
  The pilot is synthetic. The real-data experiment is BLOCKED pending
  (a) license verification for CWRU / PU / SEU, (b) research-lead
  decision on squared-vs-magnitude envelope, (c) research-lead
  decision on Paderborn KB23/24/27 class mapping, (d) research-lead
  decision on R1_Raw as the formal baseline.
- The pilot is NOT a test of any "squared-vs-magnitude envelope"
  claim. The pipeline uses Hilbert magnitude. No low-SNR validation
  exists in the repository.
- The pilot is NOT a test of the proposed linear mixed-effects
  regression. `evaluate.py` implements only the cluster bootstrap CI.
  The Hedges' g / LME pipeline is not yet implemented.
- The pilot is NOT a test of sensor remounting as a confound. P39
  (Garay 2026) documents that sensor remounting induces severe
  baseline drift; the pilot does not include a sensor-remounting
  condition.

## 6. How to reproduce (synthetic, for pipeline shape only)

```bash
cd 04_experiments/002_cross_machine_invariance/pilot
python3 synthetic/src/generate_synthetic_benchmark.py \
    --out synthetic/raw_data
# (.npz files are .gitignore-d; the directory is regenerated locally.)
cd ..
python3 -m src.run_pipeline \
    --pilot-root ../pilot \
    --representations R1_Raw R1_Env R2_Raw R2_Env R3_Order \
    --seeds 42 1337 2026 7 99 \
    --bootstrap-n 10000
```

The CSVs are written to `pilot/results/PILOT_T12_*.{json,csv}` at
end of run; per-row incremental flush is enabled by the `b6ab8b3`
fix.
