# التجارب

كل تجربة = مجلد مرقم بالصيغة:
```
0NN_<name>/
├── README.md        (السؤال، الفرضية، البيانات، Baseline، المقياس)
├── config/          (كل الإعدادات — لا قيم مُشفرة في الكود)
├── src/
├── results/
└── NOTES.md         (ماذا فشل، ماذا تعلمنا)
```

## قواعد
1. لا تجربة بدون Baseline معرف مسبقًا.
2. لا احتفال بنتيجة قبل مرورها على الـCritical Reviewer.
3. كل تجربة قابلة لإعادة التشغيل بأمر واحد.
